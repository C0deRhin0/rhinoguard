# Contributing

1. Create a focused branch.
2. Add or update tests with behavior changes.
3. Keep attack fixtures synthetic and harmless.
4. Run `python -m unittest discover -s tests -v`.
5. Run `python -m rhinoguard validate`.
6. Document new scenario fields and framework mappings.

Scenario contributions should contain a clear objective, a bounded synthetic
attack, expected findings, and remediation guidance. Never submit real secrets
or payloads intended for unauthorized targets.
