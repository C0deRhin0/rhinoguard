# Changelog

## [0.1.0] - 2026-09-07

### Added

- Deterministic scripted agent evaluations.
- Ollama and OpenAI-compatible adapters.
- Synthetic filesystem, email, HTTP, memory, and shell tools.
- Monitor, enforce, and disabled policy modes.
- Ten bounded scenarios across seven agentic-risk categories.
- Injection, leakage, tool-misuse, and behavioral detectors.
- JSON, Markdown, and standalone HTML reports with secret redaction.
- CLI, local FastAPI surface, container configuration, and regression tests.
